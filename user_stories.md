# Smart Clinic Management System - User Stories

## Admin User Stories

1. As an Admin, I want to log in securely so that I can access administrative functions.

2. As an Admin, I want to add new doctors to the system so that they can provide services through the clinic portal.

3. As an Admin, I want to view and manage registered doctors so that clinic information remains accurate and up to date.

4. As an Admin, I want to manage user access so that only authorized patients, doctors, and administrators can access protected functionality.

5. As an Admin, I want to view clinic appointments so that I can monitor clinic activity and appointment scheduling.

## Patient User Stories

1. As a Patient, I want to register and log in securely so that I can access my personal clinic portal.

2. As a Patient, I want to search for doctors by name or specialty so that I can find an appropriate doctor for my healthcare needs.

3. As a Patient, I want to view a doctor's available appointment times so that I can choose a suitable time.

4. As a Patient, I want to book an appointment with a doctor so that I can receive a consultation.

5. As a Patient, I want to view my upcoming appointments so that I can prepare for upcoming consultations.

6. As a Patient, I want to cancel or manage my appointments so that I can update my schedule when necessary.

7. As a Patient, I want to view my appointment and prescription information so that I can keep track of my healthcare.

## Doctor User Stories

1. As a Doctor, I want to log in securely so that I can access my doctor dashboard.

2. As a Doctor, I want to manage my available time slots so that patients can book appointments only when I am available.

3. As a Doctor, I want to view all of my patient appointments so that I can prepare for scheduled consultations.

4. As a Doctor, I want to view a patient's record so that I can provide appropriate treatment and ensure accurate medication.

5. As a Doctor, I want to create prescriptions for patients so that treatment information can be recorded and communicated.

6. As a Doctor, I want to view my appointments for a specific date so that I can manage my daily schedule efficiently.

## Acceptance Criteria

- Admins can securely access administrative functionality and manage doctors.
- Patients can securely log in, search for doctors, view availability, and manage appointments.
- Doctors can securely log in, manage availability, view patient appointments, and create prescriptions.
- Role-based access prevents users from accessing functionality that does not belong to their role.
- Appointment information is stored and associated with the correct doctor and patient.
